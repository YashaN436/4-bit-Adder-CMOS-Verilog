# 4-bit Adder Design (Verilog and CMOS)

## Objective
Design and simulate a 4-bit ripple-carry adder using 1-bit full adders, alongside CMOS logic and layout flow details.

## Simulation Commands
1. iverilog -o adder tb_four_bit_adder.v four_bit_adder.v full_adder.v
2. vvp adder
3. gtkwave adder.vcd
